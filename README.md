# VPN Test — Windows VPN Diagnostic

Диагностическая утилита для Windows 10/11. Она ничего не исправляет и не меняет в сетевых настройках: только делает снимок состояния сети до и после неудачной попытки подключения VPN и собирает ZIP-архив для анализа.

## Что собирает
- IP/DNS/шлюзы и маршруты
- сетевые адаптеры, включая TUN/TAP/Wintun/WireGuard
- состояние IPv4/IPv6, MTU и метрики
- сетевые службы Windows
- процессы, похожие на VPN-клиенты
- WinHTTP и пользовательский proxy
- Firewall profiles
- netstat, Winsock, сетевые драйверы/устройства в глубоком режиме
- события System, Application, RasClient, NetworkProfile и WLAN
- DNS/Ping/TCP-проверку VPN-сервера, если указать домен/IP и порт
- diff состояния ДО/ПОСЛЕ и summary.txt

Пароли, VPN-ключи, токены и содержимое сетевого трафика не собираются. MAC-адреса и имя пользователя в C:\Users\... маскируются.

## Запуск
Нужны Windows 10/11 и Python 3.10+.

Запусти `run.bat` либо:

```bat
python vpn_diagnostic.py
```

Для полного отчёта рекомендуется запуск от имени администратора.

## Как тестировать
1. Отключи VPN.
2. Запусти диагност.
3. При наличии данных укажи адрес VPN-сервера и порт.
4. Нажми **1. Снять состояние ДО**.
5. Попытайся подключить VPN и дождись ошибки.
6. Нажми **2. VPN не подключился — собрать ПОСЛЕ**.
7. В папке `reports` появится `VPN_Diagnostic_YYYYMMDD_HHMMSS.zip`.
8. Пришли ZIP в ChatGPT для анализа.

## Сборка EXE
Запусти `build.bat`. Он установит PyInstaller и создаст `dist\VPNDiagnostic.exe`.
